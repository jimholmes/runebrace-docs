Introduction To Runebrace

Key Features

  • Automatic Mesh Analysis On Load Runebrace quickly checks each mesh when it’s first loaded, and offers up fast fixes for detected issues.
  • Automatic Model Orientation One button will automatically rotate your model for an optimal orientation to minimize either islands or overhangs.
  • Highly Configurable Support Definitions Give each of your support types specific customizations for diameters, stuctures, tip types, etc. Save each as custom presets.
  • Fast Creation of Supports
    • Advanced Manual Modes Symmetry, Create Line/Arc/Cicle
    • Powerful, Focused Automated Creation Poly, Poly+Fill, Circle Fill, Triangle Paint
  • Smart Bracing and Support Consolidation
  • Powerful Support Selection and Editing
  • Fast Island Detection and Support
  • Powerful Mesh Manipulations
    • Mesh Repair
    • Resin Void Repair
    • Smoothing
    • Organic Cuts
    • Overlay Updated Model/Mesh Onto Existing Supports
  • Advanced Voxel-Based Hollowing
  • Powerful, Simple Hole Placement
  • Single-File Print Projects Models are embedded in the print project file. This lets you send one file to others without fear of losing linked models.
